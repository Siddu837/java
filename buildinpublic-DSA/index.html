// Inbuilt methods, user-defined methods, overloading & scope

📦
Inbuilt Methods
java.lang
Java's standard library provides ready-to-use methods. No need to write them — just call and use!
// Math methods Math.pow(2, 10); // → 1024.0 Math.sqrt(144); // → 12.0 Math.abs(-99); // → 99 Math.max(5, 10); // → 10 // String methods "hello".toUpperCase(); // → "HELLO" "Java".length(); // → 4
🛠
User-Defined Methods
custom
Write logic once, reuse it everywhere. Makes code cleaner and modular.
static int add(int a, int b) { return a + b; } static void greet(String name) { System.out.println("Hey, " + name); } int sum = add(5, 3); // → 8 greet("Siddu"); // Hey, Siddu
🔢
Overloading — Parameters
compile-time
Same method name, different number of parameters. Java picks the right one at compile time.
static int add(int a, int b) { ... } static int add(int a, int b, int c) { ... } add(3, 4); // → 7 (2-param) add(1, 2, 3); // → 6 (3-param)
🔄
Overloading — Data Types
polymorphism
Same name, different parameter types. Java resolves based on argument type.
static void display(int x) { ... } static void display(double x) { ... } static void display(String x) { ... } display(42); // int: 42 display(3.14); // double: 3.14 display("hi"); // String: hi
🔒
Method Scope
scope
Variables inside a method only live within that method. Other methods can't see them.
static void methodA() { int x = 10; System.out.println(x); // ✅ } static void methodB() { // println(x); ❌ not visible! int x = 99; // different x System.out.println(x); // ✅ 99 }
📦
Block Scope
scope
Variables inside a {} block only exist within that block — even inside the same method.
static void demo() { int x = 10; // method scope if (true) { int y = 20; // block scope System.out.println(x+y); // ✅ } // println(y); ❌ out of scope! for(int i=0;i<3;i++) { } // println(i); ❌ out of scope! }

Why Patterns?

Loop Mastery

Patterns train your brain to think in nested loops. Every pattern is rows × columns — master that, master all.

Why Functions?

DRY Principle

Don't Repeat Yourself. Write logic once, call it anywhere. Overloading adds flexibility with the same name.

Key Insight

Scope = Memory Safety

Understanding scope prevents hard-to-find bugs. Variables only live in their block — cleaner, safer code.

What's Next?

The Universal Pattern Formula
key insight
Every pattern follows this skeleton. Only the inner condition changes:
for(int i=1; i<=n; i++) { // outer = rows for(int j=1; j<=???; j++) { // inner = cols (changes!) System.out.print("* "); } System.out.println(); } // Half pyramid → j <= i // Inverted → j <= (n-i+1) // Floyd's → print count++ // Hollow rect → i==1||i==n||j==1||j==n // Diamond → spaces + stars formula // Binary → print (i+j)%2
